What the agent does

  1. First pass: compile, smoke run with the sample input under the time/memory cap, static sanity (main, reads input, writes output, no system()/fork()). Hangs or crashes still produce a partial report.
  2. Dispatch: every metric in the rules goes to its own analyzer: hidden tests, compiler warnings, lizard structure, modularity, generated corner cases with qwen3 counter-tests, timing-curve complexity, ASan/UBSan and leak checks, Groq readability, abstract-structure originality.
  3. Collate: weighted grade, failing inputs beside the expected output with WHY and an AI-tutor note, suggestions, JSON and text reports.

The first line contains n (0 <= n <= 1000000). The second line contains n integers, each fitting in a 32-bit
signed int. Print the sum of the n integers followed by a newline. The sum may exceed the 32-bit range and must
be printed exactly. Your solution must run in O(n) time.

Sample input:
5
1 2 3 4 5
Sample output:
15
